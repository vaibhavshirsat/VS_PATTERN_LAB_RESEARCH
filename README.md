# VS PATTERN LAB

VS FLOW-style multi-timeframe market pattern research engine.

- 5M / 15M / 1H / 4H / 1D / 1W / 1MN
- Candlestick + chart/geometry pattern research
- Trend, volume, momentum, volatility context
- Pattern lifecycle and scoring
- Multi-timeframe research
- Historical backtest with next-candle-open entry
- Research only: no broker/API integration, alerts or auto-trading

Run: double-click `START_VS_PATTERN_LAB.bat`.
